# 펌빌리티 이미지 생성 북마클릿

펌프잇업 PHOENIX 2 공식 사이트에 로그인한 상태에서 펌빌리티 상위 기록을 한 장의 PNG 이미지로 정리하는 북마클릿입니다. 별도의 서비스 회원가입이나 데이터 업로드가 필요하지 않습니다.

## 사용 방법

1. [설치 페이지](https://kim-blackcow.github.io/piu-pumbility-bookmarklet/dist/install.html)를 브라우저로 엽니다.
2. `펌빌리티 이미지 만들기` 버튼을 북마크바로 끌어다 놓습니다.
3. 드래그가 어렵다면 `새 북마크 URL용 복사`를 누른 뒤 새 북마크의 URL 입력란에 붙여 넣습니다.
4. `https://piugame.com`에 로그인합니다.
5. 공식 사이트 안의 아무 페이지에서 해당 북마크를 실행합니다.
6. 미리보기가 나타나면 `PNG 저장`을 누릅니다.

설치 페이지를 사용하지 않으려면 짧은 [`dist/pumbility-loader.txt`](dist/pumbility-loader.txt)를 복사하면 됩니다. GitHub Pages에 접속할 수 없는 환경에서는 긴 독립 실행형 [`dist/pumbility-bookmarklet.txt`](dist/pumbility-bookmarklet.txt)를 사용할 수 있습니다.

전체 북마클릿을 주소창에 그대로 붙여 넣으면 브라우저가 보안을 위해 앞의 `javascript:`를 제거하고 Google 검색으로 처리할 수 있습니다. 주소창에서 실행하려면 `javascript:`를 키보드로 직접 입력한 다음, 설치 페이지의 `주소창 실행용 본문 복사`로 복사한 코드 본문을 바로 뒤에 붙여 넣어야 합니다. 반복 사용에는 북마크 등록을 권장합니다.

## 동작 범위

- 지원 주소: `https://piugame.com/*`, `https://www.piugame.com/*`
- 공식 펌빌리티 페이지를 로그인 세션으로 백그라운드 조회합니다.
- 닉네임, 칭호, 총 펌빌리티, 상위 50곡과 곡별 실제 플레이 점수를 5열 × 10행 세로형 이미지로 구성합니다.
- 곡별 레벨볼, 랭크, 플레이트는 공식 사이트에서 제공하는 인게임 이미지 자산으로 표시합니다.
- TOP 50의 현재 최저 펌빌리티를 넘기 위한 통합 레벨과 RG 기준 최소 점수, 플레이트별 추가 펌빌리티를 안내합니다.
- 결과 이미지 우측 하단에 비공식 팬 제작물임과 게임 이미지의 권리 귀속을 표시합니다.
- 최근 접속 시간과 게임장 정보는 결과 이미지에 포함하지 않습니다.
- `mall.piugame.com`, `ucs.piugame.com` 등 별도 하위 도메인에서는 실행하지 않습니다.

## 개인정보 및 보안

- 기록, 로그인 정보, 쿠키를 외부 서버로 전송하지 않습니다.
- 짧은 로더는 GitHub Pages에서 공개된 실행 코드만 받아오며 현재 PIU 페이지 주소는 전송하지 않습니다.
- 공식 사이트와 동일 출처인 이미지 리소스만 불러옵니다.
- 비밀번호나 세션 쿠키를 읽거나 저장하지 않습니다.
- 모든 처리는 현재 브라우저 안에서만 수행됩니다.

## 가이드 계산 기준

가이드는 [PHOENIX 2 펌빌리티 실측 산식](https://mentormin.com/)과 [커뮤니티 교차 검증 자료](https://www.reddit.com/r/PumpItUp/comments/1urs8q5/phoenix_2_pumbility_formula/)를 기준으로 계산합니다. 구현된 산식은 공식 사이트에 표시된 현재 50개 기록과 소수 둘째 자리까지 모두 일치하는지 검증했습니다. 계산 레벨이 같은 싱글과 더블을 `S17 · D18`처럼 묶고, RG 기준 최소 점수와 예상 펌빌리티가 다를 때만 모드별로 나누어 제시합니다. 랭크는 두 모드 중 더 엄격한 기준을 사용합니다. 플레이트 효과는 첫 추천 레벨에서 같은 레벨·랭크를 유지했을 때 추가되는 펌빌리티로 요약합니다.

## 개발

외부 패키지 없이 동작합니다. Node.js가 설치된 환경에서 다음 명령으로 배포 파일을 다시 생성할 수 있습니다.

```powershell
npm run check
npm run build
```

주요 파일은 다음과 같습니다.

- `src/bookmarklet.js`: 읽고 수정하기 위한 원본 코드
- `scripts/build.mjs`: 한 줄 북마클릿 생성 스크립트
- `dist/pumbility-loader.txt`: GitHub Pages의 실행 코드를 불러오는 짧은 북마클릿
- `dist/pumbility-bookmarklet.txt`: 외부 실행 코드 없이 동작하는 긴 독립 실행형 북마클릿
- `dist/install.html`: 드래그 또는 복사로 짧은 북마클릿을 등록하는 설치 페이지

공식 사이트의 HTML 구조가 변경되면 선택자 수정이 필요할 수 있습니다.
